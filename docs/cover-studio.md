# 0.1.9：原生歌曲菜单与专辑封面自定义

## 范围与接入选择

本版本在正常版 0.1.8 上新增封面编辑器，保留独立版本源码及安装包；GPU 实验版保持独立。用户要求入口在歌曲右键菜单的“专辑”下方，带原生风格图标，并支持 AM / 网易云 / QQ 音乐、动态封面、本地图片及可选元数据写入。后续明确要求关键词可自由编辑，以处理错误的本地标签。

dev23 没有公开的歌曲菜单扩展点，且普通 MethodHook 的返回值写回约束仍成立，因此没有用 setResult 替换菜单。实际 Steam 1.19.2 的 MultipleTrackPopupMenu 在构建歌曲单选菜单时，通过原生 PopupMenuScope 添加专辑项。本插件在其非 synthetic 的菜单作用域实例方法返回后，核对外层调用仍精确位于 BCI 76，再在同一作用域添加一个原生项；点击、悬停、焦点与菜单关闭仍由宿主管理。Track 从该专辑项回调捕获的真实 Track 字段读取，避免使用当前播放歌曲替代右键歌曲。

开发探针曾尝试直接拦截接口上的 synthetic 默认参数桥接，独立 ByteBuddy 插桩没有生成 Advice，解析器接受目标不足以证明能触发。最终改为具体菜单作用域实例的普通方法，并通过真实宿主构建器执行到 BCI 76、调用生产 MethodHook、确认恰好新增一项及点击读取正确 Track 的隔离测试。该选择避免依赖 synthetic 桥接的过滤规则。

编辑器通过 MainWindow 内唯一的根内容调用追加独立 Dialog，避免菜单关闭时编辑器随之卸载。图片显示通过 AudioCoverImage 内唯一的 CoilImage 调用替换；没有自定义映射时以原来的十个业务参数、Composer 和已核实的默认位 488 调用原组件。自定义图片读取自身状态，歌曲列表与播放页可随映射变化重组；不修改现有 Coil 请求或宿主数据库对象。

上述菜单、根内容、Coil 入口和 SaltTheme / SaltColors 类均核对 SHA-256；指纹在 HostUiBridge 单处维护。颜色读取宿主当前主题，菜单文字、图标槽复用原生 MenuLabel；图片图标为线性矢量，不使用 emoji。窗口主体使用 Compose，深浅色保持相同布局。真实宿主解析器必须接受三个目标，不能只验证反射方法存在。

## 0.2.0：跟随宿主字体

原先编辑器的 BasicText / BasicTextField 显式构造 TextStyle，但没有设置 fontFamily；Compose 基础文字组件不会自动使用 SaltTheme 的字体，导致界面与播放器的 MiSans Regular 不一致。

现在在编辑器入口从当前 SaltTheme.textStyles 读取正文的 FontFamily，通过编辑器作用域的 CompositionLocal 传给全部文字与输入框。字体值在重组时读取；只缓存反射方法，不能缓存某一次字体选择。保留现有字号、字重、行高和布局。原生菜单项继续使用宿主 MenuLabel。新增 SaltTextStyles 类指纹检查，包内不复制或另附字体文件，也不修改用户的播放器字体设置。

隔离 Compose 场景使用宿主自带的 MiSans 资源和真实 SaltTheme local，逐项检查所有可见文字和搜索框实际排版使用的字体，并在场景中切换字体、清空搜索框和切换动态页，验证重组后仍一致。深浅色截图与交互检查沿用既有脚本；这不等同于用户正在使用的播放器窗口验收。

## 0.2.1：模组管理的开源链接

SPW 模组菜单的“开源链接”来自安装包 Manifest 中的 `Plugin-Open-Source-Url`；Steam 条目描述里的链接不会填充该菜单。0.2.1 在 Gradle spmod 配置写入 `PluginOpenSourceUrl`，指向 `https://github.com/asukua/salt-motion`。包校验同时检查根目录和 classes 内两份清单一致，并要求该字段为规范地址。当前已安装的 0.2.0 缺少字段，必须通过正常导入 / 工坊更新替换为新版才会生效，不能只修改仓库或网页说明。

## 0.2.2：SPW 1.19.3 编辑器接入

1.19.3 的菜单、根界面和图片组件混淆名称发生变化；HostUiBridge 为 1.19.2 和 1.19.3 分别登记完整指纹，在全部匹配后再启用相应反射目标。独立测试实际执行新版原生菜单构建与点击、深浅色编辑器及图片覆盖。未知宿主若不符合现有指纹则停用编辑器接入，播放页仍独立检查；后续改变内部结构仍需要重新验证和更新，不能保证任意新版本自动兼容。

## 搜索与用户选择

- 默认以本地“专辑艺人 + 专辑名”自动搜索。关键词输入框可任意修改；切换“按歌曲”时，未改动的默认词改为“艺人 + 歌名”。手动改过的词不被切换操作覆盖。
- 三来源并行请求、分别显示状态；取消旧查询会丢弃旧结果。交互候选搜索与原有严格自动匹配分开：候选允许其他版本，只有本地专辑与艺人完全一致才显示“一致”，不会凭搜索第一名自动应用。
- AM 按配置地区顺序搜索，查询词不会被错误的本地标签替换。歌曲查询使用 `include[songs]=albums`，从返回的专辑关系取得封面与专辑身份，优先使用专辑艺人；不能将 song ID 当作 album ID。交互候选最多八张不同 AM 专辑，并分别检查 editorialVideo。
- 网易云使用公开专辑 / 歌曲搜索；歌曲结果按专辑 ID 补查图片。QQ 保留返回图片的版本后缀，去掉缩略尺寸部分取得原图。两个来源未获得可验证的动态视频时，只列静态封面，不以 MV 冒充动态封面。
- 静态、动态在独立标签页显示，选中动态候选后只播放一个预览。完整视频仍按 AM 专辑 ID 复用最高档缓存；编辑器小预览输出 512，不改变保存的视频及主播放页的最高画质。

请求不使用用户登录态或账号 Cookie。图片和 API 地址有明确域名限制，重定向逐跳校验；保留原来的 OkHttp 以支持缺少 java.net.http / jdk.net 的宿主。图片、响应体及像素数均设上限。缩略图使用较小资源，选择及应用时才获取原图。

## 本地覆盖与写入职责

“应用封面”只保存插件自定义映射；“写入歌曲”才改音频文件。默认作用于当前歌曲，可显式选择本地标签一致的同专辑歌曲。专辑 / 艺人标签缺失时不扩大为同专辑范围；即使本地标签为空，当前歌曲的显式 AM 动态绑定仍可通过合成内部匹配键播放。有效显式 AM ID 可以直接复用编辑器已经缓存的同 ID 专辑目录，即使本地查找键不同，也无需重新联网；无效显式绑定仍拒绝回退。

JPEG / PNG 保留原图字节；其他可解码静态图片转为 PNG。图片限制 24 MB、边长 32～8192 且总像素不超过 33,554,432。图像按内容 SHA-256 命名；路径映射以临时文件原子发布，内存以不可变快照替换。不同歌曲可指向同一图片；映射重启后保留。取消自定义只移除插件映射，不回滚已经写入歌曲的元数据，界面明确区分这两件事。

动态视频不写入常规封面标签：通用 APIC / FLAC picture / MP4 covr 需要图片。动态候选写入其静态专辑图，视频仍留在插件缓存，界面在写入按钮附近说明。

## 0.1.10：宿主文件路径约定

用户实际报告 `Illegal character in path at index 24: file:///D:/MUSIC/Michael Jackson - Thriller.flac`。0.1.9 的 pathOf 把 SPW Vri 字符串直接传给 java.net.URI，故空格报错，`#` 被当成片段，`%20` 被误当成编码；同一辅助函数也供自定义图片映射使用。

已核实实际宿主 `androidx.compose.ui.\u0756` 的 Vri-to-file 转换：`file:///` 后是字面本地路径，`file://` 后是 UNC。0.1.10 按同一规则去前缀，再构造 Path，不做百分号解码。文件名 `a%20b.flac` 与 `a b.flac` 必须保持不同。这是宿主文件标识的约定，不是放宽 HTTP 图片地址校验；网络 URL 仍使用原有严格解析。

失败提示不能再次对同一个非法路径调用 pathOf，否则会遮蔽原始错误；文件名获取已改为容错，并把保存失败写入 diagnostics.log。补充五项路径回归，以及真实宿主转换比对、映射应用 / 重载 / 取消、257 首库内歌曲的只读路径验证和经 Vri 转换后的真实副本标签写入。

## 元数据写入与验证

新增 library-write 声明，并在写入前、每次提交前通过宿主 Manager.isPermissionGranted 检查。撤销权限、停用插件或任务取消会阻止尚未提交的替换。测试只改工作区歌曲副本，原始 D:\MUSIC 文件不写。

写入使用宿主 JAudioTagger，不另带一套标签库。先复制到歌曲旁边的私有临时文件，完整解码检查图片，再替换正面封面；其他附加图片保留。提交临时文件后重新读取，检查图片字节、附加图片、原有非封面字段及编码音频 SHA-256。原歌曲再次校验未被其他程序修改，然后创建完整原文件备份，最后原子替换。失败时原文件保持原样；整专辑按歌曲逐个提交，错误明确报告已完成数量，不声称全专辑事务回滚。

旧 MP3 的部分 ID3 文本含冗余的结尾 NUL；JAudioTagger 重写时会删除它。字段内容比较只容许该结尾终止符规范化，仍比较内部分隔符、歌词及其他文字。此兼容规则来自实际副本测试，不放宽为忽略任意文本差异。

编码音频验证：FLAC 跳过元数据块，MP3 使用真实音频起点并排除尾部标签，MP4 读取 mdat，WAV / AIFF 读取 data / SSND，DSF 读取 data，Ogg / Opus 比较排除头和评论后的音频包。它们不经过解码、转码或重新采样。格式不支持、布局无法核实、只读或文件被占用时返回失败，不绕过检查。

完整备份位于插件数据目录 `cover-backups`；自定义图片及映射在 `custom-covers`；AM 视频仍在 `motion-cache`。源码、包及完整验证记录一起保留。发布说明只记录已实际跑过的格式和宿主路径，不把离屏 UI 渲染当成正在使用的 SPW 窗口验收。
