# 0.1.7：AM 目录主搜索

## 问题与选择

用于复核的 Nirvana — Come As You Are 标签与 AM 普通版 Nevermind 一致。0.1.6 的 iTunes Search 美区查询返回 19 张候选却缺少正确专辑；日区也无精确候选，国区返回 429。直接查询 AM 专辑 1440783617 能核验身份并取得 2160×2160 动态封面。故缺陷在候选检索，跨区循环原本存在，不应靠放宽版本核对解决漏检。

同一关键词的 AM 网页目录搜索首项返回 1440783617，且普通版与多个 Deluxe 版分列。本版以该目录为主源，解析 results.albums.data；仅接受 albums 类型、有效数字 ID、匹配的 Apple 专辑 URL。AM 精确候选为零或请求非成功时使用 iTunes 备用查询；AM 出现多个精确 ID 时保留歧义，不借另一来源的排序挑选。一个地区的搜索、详情或素材未通过就继续下一地区。

搜索前还没有专辑 ID，因此公共 Web token 可从当前地区 new 页面及其声明的 index bundle 发现；手动绑定仍可使用专辑页。令牌只存内存，401/403 后重新发现一次，取消及关闭仍由原 HTTP 实现控制。发现失败的冷却按地区分别记录，避免美区页面失败后阻止日区尝试；有效 token 仍可跨地区复用。日志不输出 token、请求头、bundle 内容或完整查询 URL。

未采用去掉 Deluxe/Live 等版本词、按第一名猜测、因某候选有动画就选择该候选的方案。ISRC 可能对应多个专辑发行，歌曲反查还需要把本地歌曲上下文传入匹配器，本版未接入该阶段。当前改动优先修复已经实证的检索缺陷，不将候选更全等同于所有标签都能自动匹配。

## 诊断与音乐库审核

每个地区记录搜索源、HTTP 状态、候选总数和精确 ID 数；详情记录 HTTP 状态及是否取得经核验的方形素材。缓存仍为最多 64 项，成功六小时、失败一分钟。多个同一专辑的并发请求仍合并，手动绑定仍优先且无效绑定不自动猜测。

LibraryMotionScan 使用打包产物中的同一 AlbumCatalog 和 HlsVariants，在独立 JVM 中审核本地标签。按专辑去重，逐项写 NDJSON 检查点；元数据与查询日志不含音频、歌词或令牌。confirmed 表示专辑身份及普通方形 SDR HLS 变体通过；不表示逐首在播放器窗口播放过。未匹配、标签缺失、详情无可用方形素材和网络失败分别保留，不能统一称为“没有动态封面”。

## 验证

本版新增回归覆盖 AM 响应类型/URL、无需预知专辑 ID 的首轮搜索、成功缓存、美国无结果且 iTunes 限流后继续日本、单区 token 发现失败隔离、歧义阻止备用源猜测、搜索 token 被拒绝后的刷新，以及 iTunes 备用源仍经专辑详情核验。最终完整 JDK 与宿主裁剪运行时各 45 项测试通过；包内 PF4J / 方形圆形封面链通过，实际 AM 视频三轮各 15 个变化帧、八个上下文生命周期通过。结果保存在 build/reports/search-verification-final.log。

公开目录复核使用 Nirvana / Nevermind（AM 专辑 1440783617），核验到 2160×2160 方形视频流。网络失败和未匹配应分别诊断。
