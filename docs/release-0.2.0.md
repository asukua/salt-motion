# 0.2.0 发布验证

0.2.0 基于 0.1.10，封面编辑器跟随 Salt Player 当前字体策略，包括 MiSans Regular、系统字体与用户自定义字体；保留原来的字号、字重和布局。

## 已验证

- 完整 JDK：66 项测试通过。
- SPW 精简运行时：66 项测试通过。
- 最终安装包在真实 PF4J 中加载，HTTP 依赖启动与关闭正常。
- 方形 / 圆形播放封面连接、原生菜单和两个 UI 调用目标核验通过。
- 独立 Compose 场景检查每个可见文字和输入框的排版字体；MiSans、切换字体、恢复字体、空搜索词与动态标签页均通过，覆盖深浅色。
- 原生菜单插入及右键歌曲获取、关键词编辑、搜索 / 应用 / 写入按钮、静态图片覆盖与恢复均通过。
- 工作区生成 WAV 的写入、原标签、编码音频 SHA-256、完整备份、失败和取消检查通过。此前路径修复已在真实 FLAC / MP3 / WAV 副本验证。
- 包版本、权限、依赖和字体文件检查通过；未打包宿主库、测试代码或额外字体。

本次是字体改动，没有重复三来源在线检索和完整视频性能测试。界面截图来自生产 Compose 组件的独立场景渲染；不代替用户窗口验收。验证未更改正在运行的播放器或原始音乐文件。
