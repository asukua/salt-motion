# Salt Motion 0.2.2

适配 Steam Salt Player 1.19.3；保留 1.19.2 已知指纹。启动不再因为版本号弹出不适配提示，播放页按指纹或严格结构识别，编辑器按已知完整指纹识别。未来关键结构改变时可能需要再次适配。

- 安装包：[下载 plugin-dev.saltmotion-0.2.2.spmod](https://github.com/asukua/salt-motion/releases/tag/v0.2.2)
- SHA-256：`d66eeee651cb43a0d8343bb520debf4c493735eefdb874b454bfcb73461520c5`
- 回归：66 项测试、精简运行时包加载、宿主 1.19.3 方形及圆形调用点检查、方形 Composable 实际调用栈与连接、原生菜单插入及点击、编辑器深浅色 / 字体 / 静态封面和 WAV 工作区副本写入通过。
- 模拟未来类名与无关元数据变化可识别；关键调用改变或多个候选时拒绝接入。
- 实际 2160×2160 Highway to Hell 缓存视频在隔离测试中能持续解码并变化；生产 readImage 路径独立测得约 22 FPS，素材源帧率约 23.976，实际窗口帧率未测。
- 没有修改用户音乐、安装中的播放器或 Steam 工坊；真实窗口的动态播放、圆形布局和切歌仍需导入后验收。
